Tomato Leaf Disease Detection System

This project is an Artificial Intelligence based web application designed to detect diseases in tomato plant leaves using deep learning. The system allows users to upload an image of a tomato leaf and instantly receive a prediction along with disease information and recommended treatment.

Project Objective

The objective of this system is to assist farmers and agricultural workers in identifying plant diseases at an early stage. Early detection helps reduce crop damage, increase agricultural productivity, and support smart farming practices.

Technologies Used

  • Python – Backend programming
  • Flask – Web framework
  • TensorFlow / Keras – Deep learning model training
  • MobileNetV2 – Transfer learning CNN architecture
  • OpenCV – Image preprocessing
  • Bootstrap – Frontend styling

Dataset

The model was trained using tomato leaf images categorized into two classes: Healthy and Early Blight. The dataset images were resized, normalized, and augmented to improve model generalization.

Model Architecture

This project uses the MobileNetV2 deep learning architecture, which is a lightweight Convolutional Neural Network optimized for image classification tasks. Transfer learning was applied using a pretrained MobileNetV2 model, and additional fully connected layers were added to classify tomato leaf diseases.

  • Input Image Size: 224 × 224
  • Model: MobileNetV2
  • Optimizer: Adam
  • Loss Function: Binary Crossentropy
  • Framework: TensorFlow / Keras

Model Performance

The trained model achieved strong performance on the validation dataset. Model evaluation was performed using accuracy and loss curves.

  • Training Accuracy: 95%
  • Validation Accuracy: 93%
  • Model Type: Binary Image Classification

System Workflow

  1. User uploads a tomato leaf image
  2. The image is resized and normalized
  3. The trained MobileNetV2 model analyzes the image
  4. The model predicts whether the leaf is healthy or diseased
  5. The system displays prediction, confidence score, and recommendations
